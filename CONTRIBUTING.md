# Contributing

Enter `nix develop path:.`, then run `just fmt` and `just check` before review. See [the contributor guide](docs/contributing.md) and [architecture](docs/concepts/architecture.md) for implementation boundaries.

Stoke consumes Coopr's public `api` and `client` packages from the released source documented in [engine selection](docs/guides/coopr-api.md). Select the matching Coopr executable for runtime checks. Submit changes through a pull request.
